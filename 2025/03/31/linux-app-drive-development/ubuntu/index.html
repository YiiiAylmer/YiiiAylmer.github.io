2 Ubuntu基础操作

2.1 终端操作与PATH环境变量

  • 终端操作
    • 搜索框输入terminal
    • 右键选择 open terminal
    • 快捷键：Ctrl+Alt+T
  • 设置PATH(以添加/home/book目录为例)
    • 临时设置：export PATH=$PATH:/home/book
    • 永久设置1当前用户：修改~/.bashrc，在行尾添加或修改:
      • gedit ~/.bashrc
      • export PATH=$PATH:/home/book

2.2 常用命令

  • 目录：当前目录（pwd、.）、上级目录（..）、家目录（~）、上一个目录(-)
  • 目录文件操作命令
    • pwd: print working directory
    • cd: change directory
    • mkdir: make directory
    • rmdir: remove directory | 删除目录 | rm -rf
    • ls: list
    • cp: copy
    • mv: move
    • rm: remove | 删除文件或文件夹 | -r 递归 -f 强制
    • cat | 串联文件内容并打印 | cat file1.txt file2.txt
    • touch | 修改文件的时间，若不存在会创建空文件
  • 修改文件权限和属性命令
    • -|rwx|r-x|r-x 1 book(owner) book(group)
    • |拥有者可读写执行|同组其他用户可读执行不可写|其他用户可读执行不可写 该文件的拥有者是book，与book同组的其他用户，跟book无关系的用户
    • 原权限755如要更改为675 chmod 675 hello
    • chgrp | 改变文件所属的用户组
    • chown | 改变文件所有者
    • chmod | 改变文件权限
  • 查找/搜索命令
    • find | find 目录名 选项 查找条件 | find /home/book/dira/ -name “test1.txt” “*.txt”
    • grep | 查找文件中 符合条件的字符串 grep 选项 查找模式 文件名 | grep “WHU” */test1.txt -nwr
  • 压缩/解压命令
    • 推荐使用tar 命令：能够压缩dir
      • 压缩tar czf(create z|j file) zipfile_name.tar.(gz|bz2)fileName
      • 解压tar x(z|j)f zipfile_name.tar.(gz|bz2) [-C dir]
    • gzip | 选项 -l(list) 列出压缩文件的内容 -k(keep) 压缩或解压时保留输入文件 -d(decompress) 将压缩文件进行解压缩 | gzip -l pwd.1.gz / gzip -kd pwd.1.gz / gzip -k mypwd.1
    • bzip2 | 压缩率更高

2.3 vi编辑器

  • 命令行编辑：gedit
  • 三种模式：一般模式，编辑模式，命令行模式
  • 新建、保存（:wq）、取消保存（:q!）
  • 移动
    • 显示行号 :set number 隐藏行号 :set nonumber
    • 翻页快捷键 Ctrl + F|B
    • 跳转至某行 : row_number
    • 跳至末尾行快捷 Shift + G
  • 编辑
    • i-进入编辑模式
    • dw delete word删除单词
    • D 删除本行光标之后的所有内容
    • dd删除整行
    • ndd 删除以下n行
    • o 下方增加一行
    • u 撤销上次操作
  • 复制粘贴查找替换
    • yy 复制当前行
    • nyy 复制下面n行
    • p 当前行下方粘贴
    • /pattern 从光标处到文件尾搜索pattern n向下查找 N向上查找
    • :%s/custom/Custom/g 将文件中的custom替换为Custom，且为global全局替换
    • :%s/custom/Custom/gs 将文件中的custom全部替换为Custom，需要确认

4.2 GCC编译器使用

  • main.c-预处理-main.i-编译-main.S-汇编-main.o-链接-led.elf
  • 多文件编译
    一起编译、链接: gcc -o test main.c sub.c //编译main.c、sub.c并链接得到test
分开编译、然后链接: 
gcc -c -o main.o main.c //编译.c得到.o
gcc -c -o sub.o sub.c //编译.c得到.o
gcc -o test main.o sub.o
指定头文件目录: 
gcc -c -o main.o main.c -v -I ./ //将"./"当前目录指定为头文件目录 #include <sub.h>
  • 静态库、动态库：解决路径问题-将文件放到系统路径中|将当前目录指定为库路径
  • 有用的命令
    gcc -E main.c   // 查看预处理结果，比如头文件是哪个 
gcc -E -dM main.c  > 1.txt  // 把所有的宏展开，存在1.txt里 
gcc -Wp,-MD,abc.dep -c -o main.o main.c  // 生成依赖文件abc.dep，后面Makefile会用 
echo 'main(){}'| gcc -E -v -  // 它会列出头文件目录、库目录(LIBRARY_PATH)

4.3 Makefile使用

  • gcc -o test a.c b.c -v
    • 预处理-编译-汇编-链接
    • a.c->XXX.s->XXX.o
    • b.c->YYY.s->YYY.o
    • .o文件链接得到可执行程序test
    • 缺点：若部分文件发生修改，重新执行该命令，所有子文件都会再重新处理一遍
  • 如何解决，仅对修改的文件进行编译，最后将所有.o文件进行链接
    • 参考4.2 GCC编译器使用中多文件编译段
    • gcc -c -o a.o a.c
  • 如何判断哪些文件被修改了？
    • 比较.o与.c文件的修改时间，若a.c时间晚于a.o，说明已经被修改
  • Makefile规则
    • 目标文件：依赖文件
    • TAB 命令
    • 当目标文件不存在或依赖文件比目标文件更新，执行命令
    • 例：
      • test:a.o b.o
        • gcc -o test a.o b.o
      • a.o:a.c
        • gcc -c -o a.o a.c
      • b.o:b.c
        • gcc -c -o b.o b.c
      • 只需要执行make命令
  • Makefile语法
    • 通配符
      • %.o %.c
      • $@ 目标文件
      • $< 第一个依赖文件
      • $^ 所有的依赖文件
    • 假想目标
      • clean:
        • rm *.c test
      • 执行命令：make clean
      • 若目录中存在名为clean的文件，那么符合规则，无依赖文件
      • 使用假想目标定义 .PHONY clean
    • 变量
      • 即时变量(简单变量)
        • A:=XXX //A的值在定义时即确定
        • B=XXX //B的值在使用时才确定
        • 赋值方法 :=即时变量 = 延时变量 ?=延时变量，如果是首次定义才生效，否则忽略 += 附加且不影响即时或延时属性
      • 延时变量
      • export
  • Makefile函数
    • $(foreach var, list, text)
    • $(filter pattern…, text) //对text中取出符合pattern格式的值
    • $(filter-out pattern…, text) //对text取出不符合pattern格式的值
    • $(wildcard pattern) pattern定义了文件名的格式 wildcard函数取出当前目录中符合格式且实际存在的文件
    • $(patsubst pattern, replacement, text)//对列表中符合pattern格式的替换为replacement
  • Makefile实例
    • 改进：生成头文件依赖
      • gcc -M c.c //打印出c.c文件的依赖
      • gcc -M -MF c.d c.c //将依赖写入c.d文件
      • gcc -c -o c.o c.c -MD -MF c.d //编译c.c得到c.o并将依赖写入c.d
      • 若不支持头文件依赖，那么修改.h依赖文件后，使用make命令，无法更新编译，需要手动指定头文件依赖
      • Makefile
        objs=a.o b.o c.o
dep_files=$(patsubst %,.%.d,$(objs))
#判断是否存在.d
dep_files:=$(wildcard $(dep_files))
//判断是否含有.d依赖文件
test:$(objs)
 gcc -o test $^
#@echo dep_files=$(dep_files)

#c.o:c.c c.h
#将.d依赖文件包含进来
#如果存在.d文件，那么可以包含
ifneq ($(dep_files),)
include $(dep_files)
endif
//依赖文件列表非空，添加依赖文件
%.o:%.c
 gcc -c -o $@ $< -MD -MF .$@.d

.PHONY: clean
clean:
 rm *.o test
distclean:
 rm $(dep_files)
    • 添加CFLAGS
      • CFLAGS = -Werror 将所有warning变为Error
      • -I. 使用当前目录
      • -Iinclude 指定”include”文件夹作为搜索头文件的路径
      • gcc $(CFLAGS) -c -o $@ $< -MD -MF .$@.d
